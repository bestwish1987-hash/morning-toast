# 一人樂團（one-man-band）

使用者給一段簡譜，你回他一個「一按就有整個樂團在演奏」的網頁，外加 MIDI 檔。
所有音樂邏輯都在 `scripts/band.js`；你要做的是把譜整理成正確的文字格式、跑建置腳本、檢查結果、把成品交出去。

## 流程

### 1. 把譜整理成文字格式

譜的格式見 `references/notation.md`（先讀一遍，尤其是拍長和八度的寫法）。最常見的樣子：

```
曲名: 小星星
調: C
拍: 4/4
速度: 96
曲風: 兒歌

1 1 5 5 | 6 6 5 - | 4 4 3 3 | 2 2 1 - |
```

- 使用者貼的譜通常不完全照這個格式：把它翻成這個格式，不要改動他的音。常見的轉換：
  - 高音點 `1̇` / 上面有點 → `1'`；低音點 → `1,`
  - 底線（半拍）在文字裡常變成不見了，要從拍數推回來：一小節加起來要等於拍號的拍數。`3_4_` 黏在一起解析器看得懂，不用硬拆。
  - `1=C` `4/4` `♩=90` 這種傳統抬頭可以原樣保留，解析器看得懂
  - 五線譜或譜的照片：自己讀譜轉成簡譜，並在回覆裡把轉出來的譜貼給使用者確認
- **使用者的譜上有和弦字母**（寫在小節上方的 C、Am、F、G 很常見）：放進抬頭 `和弦:`，一小節一個；一小節裡有兩個就用 `和弦: C | Am F | G` 的寫法，或直接寫在音前面 `[Am]6 1' 3'`。使用者給的和弦以他為準，除非明顯打錯（例如和弦數比小節數多）。
- 使用者沒給的東西用合理預設：調用 C，拍號 4/4，速度和曲風留白讓曲風決定。口語講的風格（「溫柔一點」「像 KTV 那種」「搖滾」「兒歌」）對照 `references/styles.md` 選最接近的 `曲風:`；「快一點／慢一點」就在曲風預設速度上加減 15–25%。
- 只有歌名沒有譜：公有領域的歌（兒歌、民謠、古典旋律、生日快樂）自己寫譜；有版權的流行歌不要憑記憶寫旋律，請使用者提供譜。
- 把整理好的譜存成 `<輸出資料夾>/<英文檔名>.txt`。輸出資料夾：使用者有指定就照他的；否則有 scratchpad 就用 `<scratchpad>/one-man-band/`，再不然用目前目錄下的 `one-man-band-out/`。檔名用英文或拼音（會變成 .html / .mid 的檔名）。

### 2. 先檢查再建置

```bash
node <skill 目錄>/scripts/build.js <song.txt> --check
```

它會印出調性、拍號、速度（抬頭沒寫速度時這裡印的就是實際會用的速度，回覆時引用它）、每小節配到的和弦，以及「提醒」。

拍數提醒最重要（例如「第 3 小節有 3 拍，但拍號是 4/4」）：
- 第一小節和最後一小節比較短是弱起，解析器已經放行，不會提醒。
- 其他小節拍數不對，通常是底線或延長線漏了。回頭看原譜修正；看不出來就把那一小節貼給使用者問。

和弦怎麼看：
- 自動配和弦偏好主和弦，最後一小節一定收在主和弦（所以兩個一模一樣的小節，結尾那個和弦可能不同，是正常的）。
- 連續四個以上小節都是同一個和弦，而且曲風是流行、民謠、搖滾、Bossa 這類「有和弦進行才好聽」的：自己寫一組進行放進 `和弦:`（常用 I–vi–IV–V、I–V–vi–IV，小調 i–VI–III–VII），只要每小節的主要音落在和弦內音就行。兒歌、八音盒、華爾滋保持簡單沒關係。
- 旋律明顯是小調卻配了大調：抬頭改 `調: Am` 這種小調寫法。

沒問題後正式建置：

```bash
node <skill 目錄>/scripts/build.js <song.txt> --out <輸出資料夾>
```

會產生 `<name>.html` 和 `<name>.mid`。網頁是自足的（音樂邏輯和聲音全部在檔案裡，只有字型從 Google Fonts 載入，沒網路會退回系統字型，一樣能播）。`--style pop` `--lead flute` 可以臨時覆蓋譜上的設定，不用改檔。

建置後順手驗一下：
```bash
python3 <skill 目錄>/scripts/midicheck.py <name>.mid
```
最後一行要是 `OK`，主旋律那軌的 `notes=` 應該等於譜上的音符數（不含休止符和延長線）。

### 3. 交給使用者

先決定怎麼交，再寫回覆。

- **有 Artifact 工具**：用它發佈 `<name>.html`，使用者拿到可以直接在手機打開的連結。發佈時：
  - `icon: "music"`，`description` 一句話（曲名、曲風）。
  - 一定要帶 `capabilities: {downloads: true}`：頁面上的「下載 MIDI／錄成 WAV」在 artifact 檢視器裡靠這個能力存檔（會存成 .zip，解壓縮後就是 .mid / .wav）。所以 MIDI 不一定要另外送，回覆裡說頁面上能下載就好。
  - 標題就是曲名，不用加「一人樂團」之類的字。
- **有 SendUserFile**：把 `<name>.mid` 用它送出（`display: attach`）。沒有 Artifact 工具的話 `<name>.html` 也一起送。
- 都沒有：告訴使用者兩個檔案的路徑，說明用瀏覽器打開 .html 就能播。

不管哪一種，回覆都保持短，內容固定是：曲名、調、速度、曲風、配的和弦進行；頁面上能做什麼（換曲風、換主奏、調速、移調、關掉某個樂器、點小節從那裡播、最下面可以改譜重播）；有歌詞的話說一句歌詞顯示在每小節音符下方、只顯示不會唱；最後一句提進階用法（MIDI 丟 GarageBand 換真實音色；WAV 上傳 Suno 加人聲）。
不要解釋程式怎麼運作。

### 4. 使用者要改

- 「換成搖滾」「速度快一點」「主奏改鋼琴」：頁面上都可以自己調，先告訴他在哪裡調。如果他要的是「預設就這樣」，改 txt 裡的抬頭重建，再重新發佈到同一個 artifact 網址。
- 「這裡和弦不對」「改成 Am」：在譜上用 `[Am]` 指定，重建。
- 「加歌詞」：抬頭加 `詞:`，一字對一音（中文一個字、英文一個單字）。
- 「想要人聲／更真實」：這個 skill 做不到，引導去 Suno 或 GarageBand（見上面）。

## 邊界

- 聲音是瀏覽器即時合成的（鋼琴、電鋼琴、吉他、長笛、八音盒、合成器、弦樂、貝斯、鼓），聽起來是「不錯的電子琴伴奏」，不是真實錄音，也沒有人聲。使用者期待 Suno 那種成品時要先講清楚。
- 支援 2/4、3/4、4/4、6/8；三連音、反覆記號（D.C.、跳房子）不支援，反覆請直接把譜寫兩次。
- 小調：`調: Am` 表示 1=C、主音是 6（簡譜習慣），自動配和弦會用 Am 系的和弦。
- 長曲子也能做，但 WAV 錄音會花比較久（每 30 秒的曲子大約要 10–20 秒）。

## 檔案

- `scripts/build.js` — 建置腳本（txt → html + mid），`--check` 只檢查，`--json` 印解析結果
- `scripts/band.js` — 解析、配和弦、編曲、MIDI、合成器，改曲風或音色在這裡（見 `references/styles.md`）
- `scripts/midicheck.py` — 驗證 .mid 檔結構
- `assets/player.html` — 播放器頁面模板
- `references/notation.md` — 簡譜文字格式完整說明
- `references/styles.md` — 七種曲風、樂器、怎麼新增曲風
- `examples/` — 四首範例：`twinkle.txt`（基本）、`happy-birthday.txt`（3/4、弱起）、`two-tigers.txt`（傳統抬頭、半拍）、`minor-demo.txt`（小調、指定和弦）
